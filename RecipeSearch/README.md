a text-based program that reads recipes from a file and lets the user search them. It's a multi-part exercise:

Recipe: holds a recipe's name, cooking time in minutes, and list of ingredients. It prints itself in a set format.

Reading the file: the program asks for a file name, then reads the recipes from it. Recipes are separated by blank lines, with the name first, then the cooking time, then the ingredients.

Commands: a text interface where the user can list all recipes, or search by name, by maximum cooking time, or by an ingredient.
